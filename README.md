# PartyStack 🎲

The ultimate mobile party game suite for your next hangout! PartyStack brings together all your favorite party games in one sleek, arcade-style package.

## 🚀 Features

- **Truth or Dare**: Spin the wheel and face the music.
- **Charades**: Multiple categories to test your acting skills.
- **Impos-tor**: Social deduction game where secrets are everything.
- **Most Likely To**: Find out what your friends really think.
- **Who Said This?**: Guess the author of secret answers.
- **Arcade Aesthetic**: High-energy design with classic arcade fonts and vibrant colors.
- **Mobile First**: Designed specifically for passing the phone around in a group.

## 🛠️ Tech Stack

- **Framework**: [React](https://reactjs.org/) (Vite)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animation**: [Motion](https://motion.dev/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Backend / Database**: [Firebase](https://firebase.google.com/) (Auth & Firestore)
- **Fonts**: [Bungee](https://fonts.google.com/specimen/Bungee), [Press Start 2P](https://fonts.google.com/specimen/Press+Start+2P)

## 📦 Navigation and Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/[your-username]/partystack.git
   cd partystack
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Environment Setup**
   - Create a `.env` file based on `.env.example`.
   - Setup your Firebase project and add the configuration to `src/lib/firebase.ts` (or use the provided config).

4. **Run development server**
   ```bash
   npm run dev
   ```

5. **Build for production**
   ```bash
   npm run build
   ```
